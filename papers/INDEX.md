## Shared vocabulary

Every paper uses these names for these things.

| Concept | Name used | Where it is defined |
| --- | --- | --- |
| The system | Real World; its **public build** is the configuration that publishes daily receipts | *Don't Ask a Model* §1 |
| Population | About 10^5 **synthetic agents** held as numeric records; GLOPOP-S skeleton post-stratified to UN WPP 2024; never IPUMS International in anything shipped; the model is never called per agent | *Don't Ask a Model* §3.1, *Unequally Known* §4 |
| Attitudes in the public build | **Segment anchors** from published survey aggregates; donor-matched vectors replace them only for sources cleared in writing, as a new hashed version | *Don't Ask a Model* §3.1, *Unequally Known* §7 |
| Segment (v1 lattice) | Country × 3 age bands × 3 education levels, merged when small; up to about 1,800 (*Belief Assimilation* uses a coarser partition and says so) | *Don't Ask a Model* §3.1 |
| Country labels | **Coverage tier** A–D on every output (attitude evidence behind the forecasting state); **population tier** 1–4 for the population layer only (population Tier 4 = coverage tier D); **validation grade** (validated/experimental) is a display label built from population tier and dispersion checks, shown beside the coverage tier | *Don't Ask a Model* §3.1, *Unequally Known* §4.8, *Governing* §5.5 and E6 |
| Daily cycle | questions → ingest → assimilate → forecast → publish → score → learn | *Don't Ask a Model* §3 |
| Assimilation | Designed v1: per-segment iterated EKF on polls (news and search are bounded forcing; markets never assimilated). Built (engine 0.1.0): a scalar Kalman update per (country, topic) with an anchor offset, decision 0005, the default since E006. Upgrade path: the two-level filter of *Belief Assimilation*, adopted only as a new hashed version | *Don't Ask a Model* §3.5 and §7, *Belief Assimilation* §1 and §6.3 |
| Ledger | **Receipts**: beacon-selected questions committed first; salted positional Merkle leaves; signed, chained daily record; RFC 3161 tokens from two of three authorities + OpenTimestamps + public transparency log, all by the call time; git mirror carries no trust; values revealed in the clear just after the call time, once the market snapshot is published, unless the genesis policy embargoes the category | *Receipts* §4 |
| Market reference | **Market price at the scheduled call time** T*: median bid–ask mid over the 15 one-minute candles ending at T*, recomputed from venue history, with spread and volume floors; stored in a separate snapshot record, never in the leaf | *Receipts* §4.3 (P5), §5.1 |
| Scores | Brier (primary), log score clipped to [0.01, 0.99] (secondary), paired differences; inference for claims against the market is the wild cluster bootstrap-t over venue event identifiers, "not tested" below 30 clusters | *Receipts* §5 |
| Market use | **Market-blind** (no market price in inputs or assimilation; Receipts slot `rw-blind`, W in *Don't Ask a Model*, RW-blind in the Benchmark, arm M0 in *Belief Assimilation*) vs **market-aware** (`rw-aware`, W_m, RW-aware, M1) | each paper's protocol |
| LLM baseline | **Same-feed LLM**: an LLM given the same observation feed and no population (`llm-only` in *Receipts*, B1 in *Don't Ask a Model*, same-feed LLM in the Benchmark and *Governing*) | each paper's protocol |
| Forks | A user event applied to today's analysis state, run as an ensemble over 7 simulated days; never scored; shocks, not messages | *Don't Ask a Model* §3.8, *Governing* §5.1 |
| Published interval | Ensemble range × factor φ_t: a committed inflation until 20 resolved, then fitted prequentially; labelled provisional until about 100 resolved; 90% | *Don't Ask a Model* App. A.5, *Governing* §5.5 |

Ownership of claims that more than one paper touches: the confirmatory market-blind-vs-market test is *Receipts* H6 (the other papers report it as estimation, except *Belief Assimilation* H12, which tests a different forecaster version on belief-determined questions only); the matched world-vs-model test is *Don't Ask a Model* H1 (Benchmark H7 is its benchmark counterpart); fork, labelling and segment-floor rules are *Governing*'s, and the other papers point to it. The Benchmark runs its own commit and scoring rules for outside entrants and is never pooled with the Receipts record. Symbols remain paper-local (for example the anchor pull is λ in *Don't Ask a Model* and ρ in *Belief Assimilation*; "event cluster" in *Don't Ask a Model* is a coarser rule-based cluster used only for its own bootstrap and market exclusion).

## Order in which results will arrive

Each step lists what it needs from the build (slice ids from `research/decisions/BUILD_PLAN.md`) and which results it unblocks. Steps on separate lines can run in parallel.

1. **No product needed.** *Silicon Samples*: second-coder extraction and Krippendorff α (people only). *Unequally Known*: registry, `coverage.csv`, `fallback_map.csv`, `licenses.csv`, `power.json` (metadata only), then H1 skeleton fidelity (GLOPOP-S, WPP and census tables). *Correcting Variance Collapse*: feasibility census (metadata only). Licence answers gate everything that touches attitude sources in every paper.
2. **Ledger (S05) and scoring (S06) to Receipts v1, then genesis.** The pre-genesis launch ledger (target 14 Oct 2026) produces no Receipts claim. *Receipts* H1 integrity suite runs on a staging chain; H3 operations starts accruing on the first genesis day record. Every scored claim in every other paper depends on H1 passing.
3. **Model access and the scaffold's cost ledger (S01).** *Correcting Variance Collapse* pilot and fitted θ on pre-cutoff data; its protocol hash fixes the prospective start, and prospective results arrive 120 days after it at the earliest. *Unequally Known* disclosure test, which *Governing* E5 needs.
4. **Before the 27 Oct launch (stage 0).** *Governing* E5 (re-identification) and E7 (fail-closed conformance) gate the population release and daily forecasts; E3 (label persistence) as each export path ships.
5. **Population, beliefs, news, forecast and daily cycle (S02–S08).** *Receipts* pilot window, then W1 (closes at 100 H6-eligible questions, 21–90 days; analysed 60 days after close): H4 retrieval leakage, H5 call-time decomposition, H2 rerun audit and H6, the first confirmatory market comparison. *Don't Ask a Model* starts its arms the same day: day-30 σ fixes n_req; H1 runs at max(300, n_req) resolved event questions, or as "underpowered" at 365 days; H2, H3, H6 alongside; H4 and H5 accrue slowly.
6. **Filter code, no live data needed.** *Belief Assimilation* E1 synthetic truth; then E2 hindcast (needs data after model cutoffs and the feasibility floor); E3 starts only after E2 freezes its configuration and runs to its power-derived n* (demoted if projected beyond 24 months). A pass would switch the public build to this filter as a new hashed version.
7. **Forks (S09) and the event classifier.** *Governing* E1 and E2 gate public forks (stage 1); E4 and E6 need the stage-0 display and ethics review. *Don't Ask a Model* H5 uses pre-committed research forks, not public ones.
8. **Benchmark round 1 opens 1 Dec 2026** (manifest hashed 14 days before; date not yet confirmed). Track B analysis on 13 Jul 2027, Track A on 25 Jan 2028, Track C on 29 Feb 2028.
9. **Gated on written licences, timing unknown.** *Unequally Known* H2–H8; *Silicon Samples* protocol H1–H8; H9 (forward-dated wave) one survey cycle after registration.
