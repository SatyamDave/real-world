# E003: Belief assimilation converges on a synthetic ground-truth world

- Registered: 2026-10-11
- Owner seat: CTO
- Rests on: [data assimilation for ABMs](../../research/science/022-data-assimilation-abm.md), [data assimilation libraries](../../research/open-source/038-data-assimilation-libs.md), [belief update operators](../../research/engineering/065-belief-update-operators.md), [CTO lens](../../research/lenses/cto.md), [red team](../../research/lenses/red-team.md)
- Claim it earns or kills: that the morning correction moves the simulated world toward what is true, rather than toward noise or toward the model's prior. No one has shown assimilation on belief states at this scale ([data assimilation for ABMs](../../research/science/022-data-assimilation-abm.md)).

## Hypothesis

On a synthetic world whose true segment beliefs are known, capped per-segment nudging in logit space lowers the error of the estimated segment beliefs after 30 simulated days compared with no assimilation, without shrinking ensemble spread when there is no evidence.

## Primary metric

Root-mean-square error, in logit space, between estimated and true segment beliefs on day 30, nudging minus no assimilation, paired by random seed. Negative favours nudging.

## Secondary metrics

- The same error for segments never observed, which tests drift toward the prior ([data assimilation for ABMs](../../research/science/022-data-assimilation-abm.md), [red team](../../research/lenses/red-team.md)).
- Error against a persistence baseline and an ETKF arm.
- Spread-skill ratio: ensemble spread divided by actual error.
- Pass or fail of the property that with zero observations, ensemble variance does not shrink ([CTO lens](../../research/lenses/cto.md)).
- Error curve by day, to show whether the correction converges or oscillates.

## Data

Fully synthetic, generated by a seeded script committed with the results. The design is fixed now: 200 segments by 5 topics; true beliefs follow a random walk in logit space with shocks on known days; each day noisy polls observe a random 20% of segment-topic cells with known noise, and a noisy aggregate stands in for a market price. The model starts from a biased prior offset from the truth. These sizes are our choice; no source fixes them. No licence or contamination issue applies.

## Baseline

No assimilation (the prior carried forward under the same dynamics), and persistence (yesterday's observation held). Comparator: a numpy ETKF with multiplicative inflation, which must first match DAPPER's ETKF on a Lorenz-96 twin experiment within tolerance, as [data assimilation libraries](../../research/open-source/038-data-assimilation-libs.md) recommends. If that check fails, the ETKF arm is dropped and the failure reported.

## Sample size and stopping rule

50 random seeds per arm, 30 simulated days each, run once. Fixed in advance; no seeds added after looking.

## Analysis plan

95% interval for the primary metric by bootstrap over seeds (10,000 resamples). Nudging wins if the whole interval is below zero. Report every arm, every seed's summary, and the zero-evidence property result.

## Kill criterion

If nudging does not beat no assimilation, it does not enter the nightly run, and published forecasts are labelled unassimilated until a new registered experiment passes. If the zero-evidence property fails, the update operator is fixed before any other assimilation work. If the ETKF beats nudging with an interval excluding zero, that result goes to a decision record on the assimilation operator ([CTO lens](../../research/lenses/cto.md)).

## Cost cap

No LLM calls. Compute only, under one hour on one machine; the run aborts past two hours.
